butler
======

## Easy place to store files, and see text editor activity

### Vault

Upload your files with ease, and share with everyone.

#### See all the files uploaded in two different scopes

- View the content on any file
- Edit them if you are the owner
- Save the changes in the browser with ease

#### Upload your own files

- Choose which files to upload
- Choose the target directory

#### Document your folders

- Add a README.pb to the folder you want to document and click the button next
to the folder
- Write your text in Pebble to make it prettier
- Start your lines with the options described underneath followed by a whitespace
and your text:
- `-` to add a level 3 header
- `-{number}` to add a level {number} header
- `-> {text to show} @ {url}` to add anchors with links
- `-\` to show text as a code snippet
- `.` to add a list item

### Midnight

See what you've been up to and visualise your time spent coding.
